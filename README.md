# React JS Fetch Public API

## Gambaran Umum

Aplikasi ini adalah project React JS untuk menampilkan data users dari Application Programming Interface Publi dari https://jsonplaceholder.typicode.com/

## Prasyarat Instalasi

Sebelum memulai, pastikan Anda telah memenuhi prasyarat berikut:

- Node JS
- NPM (Node Package Manager)
- Koneksi Internet

## Instalasi

Ikuti langkah-langkah di bawah ini untuk menjalankan Project React JS ini:

1. Melakukan Clone Project React JS

   ```sh
   git clone https://github.com/HaikalRFadhilahh/rumahweb-fe-get-users-data.git
   ```

2. Masuk ke Folder Project
   ```sh
   cd rumahweb-fe-get-users-data
   ```
3. Install Package Yang Di Butuhkan Project React JS
   ```sh
   npm install
   ```
4. Copy File .env.example menjadi .env
   ```sh
   cp .env.example .env
   ```
5. Menjalankan project
   ```sh
   npm run dev
   ```
6. Aplikasi dapat di jalankan secara lokal dengan link
   ```sh
   http://127.0.0.1:5173
   ```
